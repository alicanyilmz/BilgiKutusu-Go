# Donanım ve Sistem Gereksinimleri

| Bileşen | Gereksinim |
|---|---|
| Cihaz | Raspberry Pi veya uyumlu Linux bilgisayar |
| İşletim sistemi | Raspberry Pi OS / Debian tabanlı Linux hedeflenir |
| Python | 3.9 veya yenisi |
| Depolama | İşletim sistemi ve seçilen dosyalar için yeterli alan |
| Ağ | İstemci cihazlarla aynı yerel ağ |
| Otomatik kurulum | systemd ve yönetici yetkisi |

Donanım üzerinde RAM/performans ölçümü yapılmadı; doğrulanmış bir minimum RAM değeri belirtilmemektedir. Varsayılan 8 eşzamanlı HTTP bağlantısı sınırı bir cihaz sayısı garantisi değildir.
